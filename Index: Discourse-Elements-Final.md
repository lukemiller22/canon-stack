## Category 1: Semantic Elements (16)

Elements identifying **meaning-making operations** in text.

1. **Concept** - An abstract or general idea representing fundamental principles
2. **Term** - A word or phrase used unambiguously
3. **Category** - A class or division grouping items by shared characteristics
4. **Domain** - A distinct sphere of activity, knowledge, or experience
5. **Subject** - A branch of knowledge to be studied or taught
6. **Topic** - A discrete area of focus within a broader subject
7. **Question** - An interrogative sentence used to review, challenge, or extend knowledge
8. **Example** - A specific instance illustrating a general idea
9. **Context** - Surrounding discourse that illuminates meaning
10. **Quality** - Characteristic features or degree of excellence
11. **Quantity** - Amount or number of something
12. **Definition** - Precise statement of meaning
13. **Description** - Detailed account of characteristics or features
14. **Relationship** - Connection between words, statements, sources, or ideas
15. **Distinction** - Clarification of differences between similar concepts *(NEW)*
16. **Ambiguity** - Acknowledgment of multiple possible meanings *(NEW)*

## Category 2: Logical Elements (15)

Elements identifying **reasoning structures and argumentative moves**.

1. **Assumption** - Basic or foundational belief underlying other beliefs
2. **Axiom** - Self-evident proposition that cannot reasonably be denied
3. **Bias** - Predisposition influencing perspective or judgment
4. **Claim** - Assertion expressing a judgment or opinion
5. **Error** - Mistaken belief, judgment, or action from faulty reasoning
6. **Conditional** - Stipulations, conditions, or limitations on claims
7. **Evidence** - Information indicating whether a belief is true or valid
8. **Warrant** - Logical connection between evidence and claim
9. **Qualifier** - Statement limiting the strength or applicability of a claim
10. **Objection** - Reason or argument opposing a belief or proposition
11. **Fallacy** - Error in reasoning based on invalid arguments
12. **Paradox** - Seemingly contradictory statement revealing deeper truth
13. **Contradiction** - Explicit logical inconsistency between statements *(NEW)*
14. **Implication** - Logical consequence stating that if A is true, then B must follow *(NEW)*
15. **Proof** - Complete logical demonstration establishing truth *(NEW)*

3. **Place** - Particular position or location in space

## Usage Context

### Separate Metadata Layers (Syntopicon Framework):
- **Concepts** - Fixed list from Index: Concepts.md
- **Topics** - Flexible Concept/Topic pairs
- **Terms** - Vocabulary inventory for discovery
- **Scripture References** - Normalized biblical citations
- **Named Entities** - Person/Place/Event/Group/Work/Period/Ideology
- **Structure Path** - Document hierarchy breadcrumb

### Discourse Elements Layer:
- Apply elements from all 11 categories above
- Format: [[Category/Element]] with brief description
- Typical: 3-8 elements per chunk
- Can combine multiple elements

### Key Distinctions:
- **Term (Semantic)** vs **Terms (metadata)**: Element tags when chunk *defines* a term; metadata lists terms for *search*
- **Topic (Semantic)** vs **Topics (metadata)**: Element tags when chunk *introduces* a topic; metadata organizes via Concept/Topic pairs
- **Question (Semantic)** vs **Query Intent**: Semantic/Question identifies questions *in* the text; Query Intent tags what questions the chunk *answers*

---

## Annotation Guidelines

1. **Descriptive, not prescriptive** - Tag what is present, not what's missing
2. **Multiple elements typical** - Most chunks have 3-8 discourse elements
3. **Namespace format** - Always use [[Category/Element]]
4. **Brief description** - Add content quote or paraphrase
5. **Confidence levels** - Can optionally tag with certainty (definitive/probable/possible)
